## 本次星图与 Grok 修复

删除失效的预设 X 请求与手工拼装 Grok 兜底，由临时后台标签页中的 X 原生页面处理当前连接。星图采用分散排列；表情名字不再切坏字符；快速连续操作先短暂等待，避免被插件本身直接拒绝。

只读查看了用户现有的真实 X 页面，确认原生转发者列表正常、新版 Grok 使用新的页面与回复呈现方式，并发现旧页面报出扩展更新后连接失效。已按用户确认重载 0.2.8，真实测试发现 X 拒绝页内加载；0.2.9 改为临时后台标签页。现已完成真实 Chrome 核验：星图从 22 位增加到 42 位，引用刷新读取 6 条；助手自动显示“连接测试成功。”。详细证据见 0.2.9 修复记录及 live-visual-checks-0.2.9.json。

## 速率修正

- 使用浏览量自身的读取时间计算平均速度，重复扫描页面不会更新旧浏览量的时间，也不会凭空产生实测增长。
- 接到新的准确页面数值或回应时更新；旧页面数值不会在普通文字变化后盖过较新的回应数值。
- 准确数量下调、归零时更新，并重置增长测量；乱序旧读数不能倒退已确认的读数。
- 缺失、简写数量、不足一分钟、无法确认发布时间时显示未知。超过五分钟没有新读数时隐藏速率，保留最后读取时间并标记过期。
- 默认本地预览不显示演示帖子与数字，也不运行监控；显式开发检查页面仍不能生成监控记录。真实扩展未包含演示帖子的固定内容。
- 只读核对了已有真实 X 详情页：准确浏览量可放在操作按钮组的辅助说明中；已编辑帖子的时间链接可能指向编辑历史。本次为前者增加准确读取，为后者停止冒充发布时间。
- 独立浏览器复现上述实际页面结构，确认 32,834 次浏览按两小时显示约 16.4K/h；只有编辑时间时显示未知。

上次已经完成真实数量对照与本地监控命中检查；本次已恢复连接并在真实 Chrome 重载 0.2.4，完成选框、弹窗和设置窗口的实机检查。速率依赖 X 提供的新读数，不能承诺秒级刷新。页面更新时间与辅助说明已明确这一限制。

## 新增问题回归检查

- 多个窗口分别修改设置，未修改项不被覆盖；普通保存不能启用 Bark、改变其服务器或设备标识。
- 实际扩展中先关闭 Bark，旧设置窗口再保存门槛，Bark 仍关闭；未经服务器授权的专用启用请求被拒绝。
- 两个星图缓存客户端同时保存，保留两条；旧缓存清理与容量预算检查通过。
- 监控记录经过 31 天后，实际存储中移除；未启用时不建立历史键；读取不触发重复写入循环。
- 推文超过 1,500 条后，推文和速度记录同步淘汰；趋势最多 60 点，乱序旧读数不重置有效增长。
- 12K、12 K、10万、10 万、1.2M 和不可靠分隔形式显示未知；精确逗号数量和零正确保留。
- 发送尝试在请求前计数，失败等待跨后台重启保留；测试、重试共用限制。
- 安静时段跨午夜与不跨午夜判断、合并最多十条、停用后不补发、单独目标门槛检查通过。
- 长合并通知限制在小体积请求中，不附带推文正文。
- 大响应读取过程超限停止，跨分块中文与表情保留正确。
- 备份不含 Bark 标识，恢复后监控关闭；错误格式与超限文件拒绝。

## 新增实际操作

1. 模板跨入口同步；未保存时切换分区，继续编辑与放弃均有效。
2. 移除详情页原推文后，已确认的回复仍被过滤；屏蔽原因可见，临时恢复与作者白名单生效。
3. 本机自检读取当前独立扩展页面的真实状态；导出不含测试设备标识、正文、账号名或推文链接。
4. 下载设置备份，检查字段；导入先预览，确认后恢复，Bark 与监控关闭。
5. 设置安静时段、合并分钟、发送间隔、单独目标门槛，重新打开弹窗后仍保留。
6. 接收更新读数后打开趋势；在选择窗口勾选推文并下载 Markdown，文件只包含所选项。
7. 合成 Pro 多列页面选择列，分别设置条数、浏览量和监控，实际热榜按所选列变化。
8. 新工具中文、日文和窄窗口检查通过。

## 六项 Firefox 提示

- 两项为最低 Firefox 版本早于新版可选数据发送声明。Bark 在 Firefox 140 以下停用，本地功能仍可使用；Android 不在支持范围。
- 四项来自构建后的 React 通用代码中的内部 HTML 写入分支。项目正文按文字渲染，没有将 X 正文直接作为 HTML 插入。

没有把六项提示描述为零提示，也没有将依赖检查描述为完整安全审计。

## 复查方式

```sh
npm ci
npx playwright install chromium firefox
npm run release
```

`npm run verify:release` 只运行完整检查并生成对应记录；`npm run release` 在检查通过后继续打包，交付到当前版本目录。修改实现或检查脚本后，旧检查记录不能用于新的交付。
