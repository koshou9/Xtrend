# Xtrend 0.3.0 优化范围、实施与验收

日期：2026-10-25。保留现有核心功能和页面读取、内容整理、核心计算、界面、本机后台的分工。

## 完成标准

- 原有阅读、过滤、热榜、图片、复制、星图、草稿、设置和通知继续通过检查。
- 网页脚本无法要求扩展创建星图或草稿任务；实际用户按钮仍能完成操作；网页模拟点击也不能触发生成。
- 页面切换后清除旧窗口及临时页面；增删列后身份不会重复。
- 六项新增能力有真实入口，能完成保存、读取、取消和导出等完整流程。
- 输入、存储上限、未知数量、重复事件、外部文字等边界有检查。
- 新安装包对应本次源码和本次检查结果，不沿用旧版本验收结论。

## 优先级、问题与修复办法

| 优先级 | 项目 | 范围与方案 | 验收方式 |
|---|---|---|---|
| 高 | 网页消息触发草稿 | 敏感操作通过插件内部通道；移除普通网页消息到后台任务的转交和旧请求重放 | 同时发送两种旧消息，确认不打开后台页；用户点击后仍能生成 |
| 高 | 遗漏问题的检查 | 把本次三个复现过程加入浏览器检查；补输入与保存边界 | 每次交付运行，任何一项失败阻止打包 |
| 中 | 旧窗口与后台页残留 | 切换页面清空窗口并重置连接；取消、账号切换、关闭及过期保留清理 | 打开星图后切换页面，检查窗口和后台页均关闭 |
| 中 | 多列身份重复 | 当前页面的列使用递增且不重复的身份 | 移除第一列再新增列，选项身份仍各不相同 |
| 中 | 开发工具安全问题 | 更新受影响测试与图片工具；交付时检查全部依赖 | 已知问题检查通过后才能交付 |
| 中 | 文档不一致 | 统一新操作方式、5MB星图预算、收藏保存范围与真实验证边界 | 对照实际常量、入口和生成结果核对 |
| 中 | 真实环境缺口 | 保留单独验收表，提供各浏览器安装包和操作步骤 | 登录账号、Pro权限、手机收件和商店签名分别确认 |

## 新增功能与使用方式

| 优先级 | 功能 | 实现范围与价值 | 使用与检查 |
|---|---|---|---|
| 中 | 收藏、标签与备注 | 手动保存选中帖子；100条／2MB；不自动删除旧收藏；跨本机账号共享 | 帖子旁收藏按钮→填写→保存；重开收藏确认仍在；可单独导出和移除 |
| 中 | 过滤规则试用 | 使用当前未保存的规则及黑白名单；与真实过滤共用判断 | 弹窗过滤分区→试用过滤规则；输入示例和作者，查看将隐藏或将保留 |
| 中 | 阅读场景 | 日常阅读、资料收集、重点热帖；只修改热榜显示 | 热榜设置或弹窗排名分区→阅读场景；确认监控和通知未被开启 |
| 中 | 本页搜索 | 正文、作者、发布时间联合筛选；只处理本页已读取内容 | 展开热榜搜索；输入和清空筛选，确认数量正确 |
| 中 | 再次提醒 | 默认关闭；可选浏览量增长25%、50%、100%；至少5分钟并需要新准确读数 | 监控分区选择比例；检查不足比例、旧读数、短间隔均不重复提醒；重启仍去重 |
| 低 | 表格导出 | 只导出勾选内容；保留读取时间；外部文字按普通文字处理 | 批量选择窗口→下载表格；核对只有所选帖子 |

收藏单独保存和导出，不包含在设置备份中。保存的正文可能包含用户认为敏感的信息，请在共享设备或发送导出文件前核对内容。

## 改善方向与实施步骤

1. **性能：**先合并一批新读数，再统一计算热榜；通过计数检查确认批量输入不会逐条重复刷新。缓存清理先比较结果，未变化时不重复保存。
2. **代码质量：**敏感操作只留一条处理路径；删除因此失去用途的旧请求重放和页面转交代码。输入校验、大小限制和取消能力保留。
3. **可维护性：**收藏、搜索、导出和场景沿用核心逻辑与现有界面分工；规则试用直接使用正式过滤判断，避免两套规则偏离。
4. **用户体验：**复用现有窗口、表单与三种语言；新增输入有明确标签，结果和错误可被键盘及辅助工具读取；标明数据范围和更新后刷新步骤。
5. **交付检查：**更新依赖→格式和代码检查→功能检查→三种构建→浏览器操作→Firefox载入和提示检查→确认结果对应当前源码→生成安装包。
6. **自动检查：**已增加提交和合并请求触发的检查配置，使用相同交付流程；托管平台上的实际运行需要提交到仓库后另行确认。
7. **安装更新：**本次交付三种浏览器压缩包和安装说明。商店自动更新及Firefox永久安装还需要商店账号、签名和审核，不能由本地打包代替。

## 本机复查方式

环境：Node.js 22.12以上的22.x，或24.x。首次运行安装依赖和检查所需浏览器。

```sh
npm ci
npx playwright install chromium firefox
npm run verify:release
npm run release
```

`verify:release`生成检查结果；`release`通过全部检查后生成当前版本安装包和源码包。检查截图和结果在`test-results/`，交付内容在`release/0.3.0/`。详细结果以`VERIFICATION.md`和交付包内本次检查记录为准。

## 真实环境边界

本次新增和回归检查使用隔离的构造页面，不使用用户登录资料，不向真实X或Grok提交提示词。历史0.2.9真实Chrome通过的结果仅属于当时版本，不能替代0.3.0的新验收。真实Pro、Edge、Firefox账号流程、Bark手机收件和商店签名仍需各自的实际环境。

## 本次性能对照

在相同构造输入下，保留1500条帖子并接收1000条更新：状态通知从1001次减少至1次，本机仅计算用时从约107毫秒降至约2毫秒。该结果不包含真实X页面的绘制成本，不代表所有设备有相同速度。原始对照保存在检查目录。

## 最终验收结果

147项功能与边界检查、111项浏览器操作检查全部通过，三个浏览器版本成功生成，全部依赖的已知问题检查未报出问题。三个已复现问题和六项新增能力均包含在本次检查中。Firefox仍有6项已说明的提示。完整安装包、源码、说明和对应结果位于`release/0.3.0/`。真实账号、手机收件、商店发布及托管平台运行继续按前述边界单独验收。
